# 잡코인 펌핑 되돌림 숏 — 전략 정리

`research/` 백테스트(바이낸스 USDⓈ-M, 2021~2026-10 데이터)로 정한 실거래 후보 규칙이에요.
근거는 [`README.md`](README.md) 8~24번을 보세요. 시각은 한국 시간(KST) 기준이에요. 바이낸스 일봉은 매일 09:00 KST(00:00 UTC)에 마감돼요.

## 아이디어

"알트는 장기적으로 우하향"은 맞아요. 하지만 장기 숏은 중간 펌핑(+50~100%)에 청산당해서 수익이 거의 남지 않아요(README 10번).
그래서 **시장이 조용한 날 혼자 크게 펌핑한 잡코인이 되돌리는 구간만 짧게 먹고, 안 되면 빨리 나오는** 방식으로 우하향을 조금씩 수확해요.
여기에 **기존 코인이 업비트·빗썸·바이낸스 현물에 새로 상장될 때 생기는 상장빔**이 상장 후 되돌리는 구간을 같이 먹어요. 두 신호는 서로 다른 날, 다른 코인에서 나와서 놀던 돈을 채워줘요.

## 규칙 1: 메인 (일봉 +20% 펌핑 되돌림)

| 항목 | 내용 |
|---|---|
| 거래소 | 바이낸스 USDⓈ-M USDT 무기한 선물 (코인만 대상. 주식·원자재·RWA·스테이블·지수 제외) |
| 대상 | 직전 30일 평균 거래대금 **100위 밖** 코인 (50·70위 밖으로 넓히면 나빠짐, README 21번) |
| 확인 시각 | 매일 **09:00 KST** 일봉 마감 직후 하루 한 번, 확인 즉시 진입 (다른 시각이나 늦은 진입은 나빴음, README 18~19번) |
| 진입 조건 | ① 전날 일봉 종가가 그 전날 종가보다 **+20% 이상**<br>② 바이낸스 전체 계정 롱숏비율 **> 1.5** (09:00 직전 5분 스냅샷)<br>③ 그날 BTC·ETH·SOL 평균 수익률이 **−3% ~ +7%** 사이<br>④ 신호 날 종가가 그날 고가 대비 **30% 넘게 밀리지 않았을 것** (윗꼬리 필터, README 20번)<br>⑤ 진입 시점 펀딩비가 **4시간·8시간 주기 −1% 이하, 1시간 주기 −0.5% 이하가 아닐 것** (README 23번)<br>⑥ 예전에 손절·청산 난 적 없는 코인<br>⑦ 그 코인에 열린 포지션 없음 |
| 진입 | 숏, **isolated 1배**. 09:00 가격(그 시간 1시간봉 시가) **+0.5%**에 숏 지정가를 걸어요. **10:00까지 안 잡히면** 취소하고 10:00에 즉시체결 지정가(IOC, 매수호가 대비 최대 −0.3%)로 진입해요. 못 채운 물량은 버려요 (README 22번) |
| 익절 | 진입가 **−15%**. 진입 직후 바로 걸어둠. 단 10시 대비책으로 **09:00 시가보다 낮게** 들어갔으면 지정가가 노렸던 가격(09:00 시가 × 1.005 × 0.85)에 걸고, 10시 가격이 이미 그 아래면 진입하지 않음 (README 28번) |
| 손절 | 진입가 **+15%**에 reduce-only 스탑마켓. 진입 직후 바로 걸어둠 |
| 시간 청산 | 진입 **48시간 후** 남은 포지션은 시장가로 정리 (3일보다 수익은 비슷하고 낙폭이 작음, README 17번) |
| 영구 제외 | 손절(또는 청산)이 난 코인은 다시 숏하지 않음 |

## 규칙 2: 상장빔 숏

| 항목 | 내용 |
|---|---|
| 대상 | 바이낸스 USDT 무기한 선물에 **30일 이상** 상장돼 있던 코인 (신규 코인 TGE 상장은 제외) |
| 신호 | 그 코인이 **업비트 원화마켓, 빗썸 원화마켓, 바이낸스 현물(USDT)** 중 한 곳에 새로 상장돼 거래가 시작됨 |
| 진입 | 거래 시작 **1시간 뒤** 바이낸스 선물에서 숏, isolated 1배, 즉시체결 지정가(IOC, 최대 −0.3%). 상장 직후 바로 숏하면 첫 시간에 한 번 더 튀는 경우가 많아서 나빴어요 (README 24번) |
| 익절 / 손절 / 시간 청산 | 메인과 같음: **−15% / +15% / 48시간** |
| 기타 | 이미 같은 코인을 들고 있으면 건너뜀. 손절해도 그 코인을 제외 목록에 넣지 않음 |

## 크기: 단계별로 올리기

두 규칙이 같은 계좌, 같은 크기 규칙을 써요. 거래 한 번의 결과는 편차가 커요(평균 +2%, 표준편차 13%). 그래서 실전 성과를 확인하면서 올려요.

| 단계 | 거래당 증거금 | 최대 동시 포지션 | 다음 단계로 가는 조건 |
|---|---|---|---|
| 0 | 페이퍼 (12%로 기록) | 7 | 1~2개월. 신호와 가상 체결이 규칙대로 나오는지 확인 |
| 1 | **5%** | 18 | 실전 **60번 이상 거래** + 실제 진입 슬리피지 평균 **0.3% 이하** + 지정가 체결률 **75% 이상** + 거래당 평균 **0% 이상** + 봇 오류 없음 |
| 2 | **12%** (기본이자 상한. 메인 신호 중 롱숏비율 2.0 이하는 절반인 6%, README 33) | 7 | 더 올리지 않음. 두 규칙을 같이 돌리면 동시 포지션이 늘어서, 15%면 최대 낙폭이 −31%까지 커졌어요 |

증거금 합계는 자본의 90%를 넘기지 않아요. 넘으면 새 신호를 건너뛰어요.

## 안전장치

- 익절·손절은 **거래소 쪽 주문**이라 봇이 꺼져도 작동해요.
- 크기를 줄이거나 멈추는 기준이에요. 해당하면 텔레그램으로 알려요.

  | 상황 | 조치 |
  |---|---|
  | 12%에서 고점 대비 −25% | 8%로 내림. 고점을 회복하면 12%로 복귀 |
  | 어느 단계든 고점 대비 −35% | 새 진입 중단, 원인 점검 |
  | 최근 100번 거래 평균이 −1.5% 미만 | 새 진입 중단 |

  - 크기를 줄이는 기준(−25%)은 백테스트 최대 낙폭(12%에서 −20~−23%)보다 조금 깊게 잡았어요. 이보다 얕게 잡으면 정상적인 흔들림에도 걸려서, 낙폭은 못 줄이고 회복 구간 수익만 깎여요. 메인만 15%로 돌릴 때 −15%에서 줄이도록 했더니 최대 낙폭은 그대로이고 최종 금액만 6~15% 줄었어요.
  - 100번 거래 평균 기준은 백테스트에서 나온 최저치(−1.1~−1.8%)보다 나쁘면 전략이 깨진 걸로 보는 거예요. "최근 3개월 평균 마이너스"는 좋은 전략도 14~18%의 시간 동안 걸리는 조건이라 쓰지 않아요.
- API 키는 선물 거래 권한만 켜고, 출금 권한은 끄고, VPS IP만 허용해요.

## 백테스트 결과 (2024-01 ~ 2026-10, 1만 달러 시작, 거래당 12%)

두 규칙을 한 계좌에서 같이 돌린 결과예요(`combined.py`, README 24번). 펀딩비는 실제 과거 기록으로 정산했어요. 같은 날 신호가 여러 개면 어떤 걸 먼저 잡는지는 무작위라, 순서에 따라 ±10% 정도 달라질 수 있어요.

| 슬리피지 (진입·청산 / 손절) | 최종 | 연환산 | 최대 낙폭 | 2024-01~2025-06 | 2025-07~2026-10 |
|---|---|---|---|---|---|
| 0.1% / 0.5% (기본 가정) | $56,500 | +84% | −20% | $20,600 | $27,400 |
| 0.3% / 1.0% | $43,100 | +67% | −23% | $19,100 | $22,600 |
| 0.5% / 1.5% | $34,000 | +54% | −25% | $17,600 | $19,300 |

기간별 금액은 각 구간을 1만 달러로 새로 시작한 값이에요.

- 거래는 메인 약 480번, 상장빔 약 200번이에요. 합쳐서 한 달 20건 정도예요.
- 메인은 거래당 평균 +2.0%, 승률 63%예요. 익절 34%, 손절 31%, 48시간 정리 35%이고, 지정가 체결률은 86%예요("닿으면 체결"로 판단한 값이라 실제는 더 낮을 수 있어요).
- 상장빔은 거래당 평균 +2.8%, 승률 67%예요(슬리피지 0.3%면 +2.3%).
- 메인만 거래당 15%로 돌리면 $41,700(최대 낙폭 −16%)이에요. 상장빔을 더하면 거래가 늘어서 금액이 커지지만 낙폭도 커져요.

## 알고 있어야 할 한계

- **조합과 필터는 같은 데이터를 보면서 골랐어요.** 롱숏비율(1.5), 메이저(−3% / +7%), 보유 기간(2일), 윗꼬리(30%) 기준이 모두 그래요. 실전 성과는 백테스트보다 낮다고 보는 게 맞아요.
- **펀딩비 필터는 효과가 거의 없었어요.** 34개월 동안 19건만 걸렀고, 그 거래들의 평균은 오히려 +0.5%였어요. 숏이 펀딩비를 크게 내는 드문 경우를 막는 안전장치예요.
- **상장빔 규칙의 한계**: 상장 1시간 뒤 진입은 네 가지 진입 시각을 비교해서 고른 거예요(두 기간 모두 플러스). 업비트·빗썸 티커가 바이낸스 선물과 같은 코인인지 따로 검증하지 않았어요(티커가 겹치는 다른 코인일 수 있음). 상장폐지된 원화마켓은 데이터에서 빠졌어요.
- **윗꼬리 필터는 근거가 약해요.** 해당 신호가 24건뿐이고, 기준을 25%·35%로만 바꿔도 효과가 작아지고, 40%에서는 오히려 손해였어요. 안전장치 정도로 보세요.
- **수익이 롱숏비율 필터에 크게 의존해요.** 필터를 빼면 2025~26년은 손실이었어요. 바이낸스가 이 지표를 바꾸거나 시장 참여자 습관이 바뀌면 효과가 사라질 수 있어요.
- **거래당 수익이 해마다 줄고 있어요.** 필터를 통과한 신호 전체 기준으로 2024년 +3.0%, 2025년 +1.9%, 2026년 +0.5%예요(README 16번). 2026년 2~4월에는 −27%가 났어요. 중단 규칙을 지키는 게 중요해요.
- 1시간봉 기준이라 봉 안의 움직임은 단순하게 처리했어요. 같은 봉에서 익절과 손절이 둘 다 닿으면 손절이 먼저 된 걸로 쳤어요.
- 거래대금 순위를 시가총액 대신 썼어요. 시가총액 200M 이하 조건은 시가총액 데이터가 없어서 아직 테스트하지 못했어요.
- 바이낸스와 바이빗은 한국 금융정보분석원(FIU)에 신고되지 않은 해외 거래소예요. 앱 차단과 웹 차단 위험, 세금 신고는 본인이 확인해야 해요.

## 진행 순서

1. **페이퍼 모드** (1~2개월): 실시간 데이터로 신호와 가상 체결을 기록하고 백테스트와 비교해요. 봇과 실행 방법은 [`pumpfade/README.md`](../pumpfade/README.md)에 있어요.
   - 비교용으로 전부 시장가, 절반씩 진입도 같은 신호로 따로 기록해요. 실제 호가창으로 슬리피지와 지정가 체결률을 재요.
   - 3일 보유 버전도 같이 기록해요. 손절 2 × ATR, 17:00 KST 확인, 시간봉 진입, 메이저 ±3% 필터는 아직 봇에 없어요.
2. **바이낸스 선물 테스트넷**: 실제 주문 흐름(+0.5% 지정가, 10:00 취소와 진입, 익절·손절 주문, 48시간 정리)을 확인해요.
3. **실거래**: 위 크기 단계표대로 5%로 시작하고, 조건을 채우면 12%로 올려요.

준비물: 도쿄나 서울 VPS(월 $5~10, 고정 IP), 바이낸스 API 키(테스트넷용 따로), 텔레그램 봇(선택).
수수료: 메이커 0.02% / 테이커 0.05%예요. BNB로 내면 10% 할인돼요. API로 주문해도 같아요.
노는 자금(평균 90% 이상)은 유연 예치에 넣어두고, 신호가 뜰 때만 선물 지갑으로 옮기는 걸 권해요.
