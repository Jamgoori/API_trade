# 잡코인 펌핑 되돌림 숏 — 전략 정리

`research/` 백테스트(바이낸스 USDⓈ-M, 2021~2026-10 데이터)로 정한 실거래 후보 규칙이에요.
근거는 [`README.md`](README.md) 8~15번을 보세요.

## 아이디어

"알트는 장기적으로 우하향"은 맞지만, 장기 숏은 중간 펌핑(+50~100%)에 청산당해서 수익이 거의 남지 않아요(README 10번).
그래서 **혼자 크게 펌핑한 잡코인이 되돌리는 구간만 짧게 먹고, 안 되면 빨리 나오는** 방식으로 우하향을 조금씩 수확해요.

## 규칙

| 항목 | 내용 |
|---|---|
| 거래소 | 바이낸스 USDⓈ-M USDT 무기한 선물 (코인만 대상. 주식·원자재·RWA·스테이블·지수 제외) |
| 대상 | 직전 30일 평균 거래대금 **100위 밖** 코인 |
| 확인 시각 | 매일 **00:00 UTC (09:00 KST)**, 하루 한 번 |
| 진입 조건 | ① 전날 일봉 종가가 그 전날 종가보다 **+20% 이상**<br>② 바이낸스 전체 계정 롱숏비율 **> 1.5** (00:00 직전 5분 스냅샷)<br>③ 그날 BTC·ETH·SOL 평균 수익률이 **−3% ~ +7%** 사이<br>④ 예전에 손절·청산 난 적 없는 코인<br>⑤ 그 코인에 열린 포지션 없음 |
| 진입 | 숏, **isolated 1배**. 가격 상한이 있는 즉시체결 지정가(IOC, 매수호가 대비 최대 −0.3%)로 넣고, 남은 물량은 취소 |
| 크기 | 거래당 증거금 = 현재 자본의 **10~15%**. 동시에 최대 6개(증거금 합계 90% 이내) |
| 익절 | 진입가 **−15%**에 reduce-only 지정가 매수(메이커). 진입 직후 바로 걸어둠 |
| 손절 | 진입가 **+15%**에 reduce-only 스탑마켓. 진입 직후 바로 걸어둠 |
| 시간 청산 | 진입 **72시간 후** 남은 포지션은 시장가로 정리 |
| 영구 제외 | 손절(또는 청산)이 난 코인은 다시 숏하지 않음 |

## 안전장치

- 익절·손절은 **거래소 쪽 주문**이라 봇이 꺼져도 작동해요.
- 아래 경우에는 봇이 새 진입을 멈추고 텔레그램으로 알려요.
  - 자본이 고점 대비 **−35%** 이상 빠졌을 때
  - 최근 3개월 거래당 평균 수익이 마이너스일 때
- API 키는 선물 거래 권한만 켜고, 출금 권한은 끄고, VPS IP만 허용해요.

## 알고 있어야 할 한계

- **조합과 필터는 같은 데이터를 보면서 골랐어요.** 롱숏비율 기준(1.5)과 메이저 기준(−3% / +7%)도 마찬가지예요. 실전 성과는 백테스트보다 낮다고 보는 게 맞아요.
- **수익이 롱숏비율 필터에 크게 의존해요.** 필터를 빼면 2025~26년은 손실이었어요. 바이낸스가 이 지표를 바꾸거나 시장 참여자 습관이 바뀌면 효과가 사라질 수 있어요.
- **2026년은 +8%로 약해졌어요.** 중단 규칙을 지키는 게 중요해요.
- 1시간봉 기준이라 봉 안의 움직임은 단순하게 처리했어요. 같은 봉에서 익절과 손절이 둘 다 닿으면 손절이 먼저 된 걸로 쳤어요.
- 거래대금 순위를 시가총액 대신 썼어요. 시가총액 200M 이하 조건은 시가총액 데이터가 없어서 아직 테스트하지 못했어요.
- 바이낸스와 바이빗은 한국 금융정보분석원(FIU)에 신고되지 않은 해외 거래소예요. 앱 차단과 웹 차단 위험, 세금 신고는 본인이 확인해야 해요.

## 진행 순서

1. **페이퍼 모드** (1~3개월): 실시간 데이터로 신호와 가상 체결을 기록하고 백테스트와 비교해요.
   - 시간봉 진입(+20%, 메이저 필터)과 메이저 ±3% 필터는 비교용으로 나란히 기록해요.
2. **바이낸스 선물 테스트넷**: 실제 주문 흐름(진입, 익절·손절 주문, 72시간 정리)을 확인해요.
3. **실거래 소액**: 거래당 5%로 시작해서 실제 슬리피지를 측정해요.
4. 문제없으면 거래당 10~15%로 올려요.

준비물: 도쿄나 서울 VPS(월 $5~10, 고정 IP), 바이낸스 API 키(테스트넷용 따로), 텔레그램 봇(선택).
수수료: 메이커 0.02% / 테이커 0.05%예요. BNB로 내면 10% 할인돼요. API로 주문해도 같아요.
