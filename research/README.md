# 잡코인 숏 리서치 (바이낸스 USDⓈ-M 선물)

질문 두 가지:
1. 잡코인 선물을 기계적으로 숏하는 "양계장"이 돈이 되나?
2. 펌핑 신호로 "손절해야 할 펌핑"과 "곧 덤프될 펌핑"을 구별할 수 있나?

전체 결과 표는 [`results/report.md`](results/report.md)(1~4)와 [`results/farm_filter.md`](results/farm_filter.md)(5)에 있어요. 원자료는 `results/*.csv`예요.

## 데이터

- `binance_data.py`가 [data.binance.vision](https://data.binance.vision)에서 1시간봉, 펀딩, 5분 단위 OI·롱숏비율을 받아요.
- **상장폐지된 코인도 포함돼요.** 죽은 코인까지 다 들어간 표본이에요.
  - 바이낸스는 상폐 후에도 거래량 0에 가격이 멈춘 봉을 계속 올려둬요. 마지막 거래 시점에서 잘라냈어요.
- 주식, 원자재, FX, 상장 전 주식(pre-IPO), 지수, RWA, 스테이블코인 선물은 `exchangeInfo`의 `underlyingType`/`underlyingSubType`으로 걸러냈어요.
- 대상은 코인 670개(상폐 161개 포함), 기간은 2021-01부터 2026-10까지예요. OI·롱숏비율은 2021-12부터 있어요.
- 원본 파일은 `data/binance/`에 캐시돼요(gitignore 대상, 약 1GB).

```bash
python3 research/binance_data.py --start 2021-01 --end 2026-10 --workers 48
```

```bash
python3 research/short_study.py --part all > research/results/report.md
```

```bash
python3 research/farm_filter.py
```

```bash
python3 research/blowup_features.py 2025_2026 > research/results/blowup_2025_2026.md
```

## 가정

- **티어**: 직전 30일 평균 거래대금 순위예요. 그날 이전 데이터만 써요. "101+"는 거래대금 100위 밖이에요.
- **체결**: 1시간봉 시가에 진입해요.
  - 테이커 수수료 0.05%, 슬리피지 편도 0.1%
  - 손절 체결은 슬리피지 0.5%를 추가하고, 손절가와 봉 시가 중 불리한 쪽으로 체결해요(갭 반영).
- **펀딩**: 매 펀딩 시점에 현재 노셔널 기준으로 정산해요.
- **Isolated 청산**: 유지증거금 2.5%로 가정했어요. 청산되면 그 포지션 증거금 전액을 잃어요.
- **펌핑 신호**: 4시간 수익률 +20% 이상, 그리고 그 시간 거래대금이 직전 7일 시간당 평균의 5배 이상
- **BTC 헤지**: 숏마다 같은 노셔널의 BTC 롱을 같이 열고 닫아요. 증거금이 추가로 필요해요.

## 결과

### 1. 양계장(잡코인 전부 숏)은 손실이 났어요

30일마다 해당 티어 코인 전부를 같은 증거금으로 숏하고 30일 보유했어요. 2021-02부터 2026-09까지 67개 코호트, 101+ 티어는 코호트당 평균 175개 코인이에요.

| 티어 | 레버리지 | 손절 | 연환산 | 최대 낙폭 | BTC 헤지 시 연환산 |
|---|---|---|---|---|---|
| 101+ | 1x | 없음 | −45% | −98% | −24% |
| 101+ | 1x | +30% | −32% | −91% | −14% |
| 101+ | 1x | 펌핑 신호 시 청산 | −42% | −96% | −20% |
| 101+ | 1.5x | 없음 | −76% | −100% | −48% |
| 31–100 | 1x | +30% | −23% | −78% | +2% (낙폭 −58%) |

- 연도별(101+, 1x, 손절 없음)로는 2025년(+8%)만 플러스였어요. 2022년 하락장에서도 −17%였어요.
- 이유는 두 가지예요:
  - 하락장 중간의 반등장(30일 +30~35%)이 숏을 크게 깎아요.
  - 매달 다시 진입하는 구조라 변동성 손실(volatility drag)이 생겨요.
- 손절은 손실을 줄이지만 플러스로 만들지는 못했어요. 펌핑 신호 청산은 단순한 +30% 손절보다 못했어요.

### 2. 펌핑 직후는 동전 던지기예요. 대부분 떨어지지만 평균은 0이에요

펌핑 신호 3,693건을 봤어요.

- 7일 뒤 수익률은 **중앙값 −11.3%, 평균 −0.5%**였어요. 대부분 떨어지지만 소수가 크게 더 올라서 평균이 0이 돼요.
- 추가 +20%와 −20% 중 어느 쪽에 먼저 닿는지는 **44% 대 43%**로 거의 반반이었어요.
- 신호 후 7일 안에 **10%가 추가로 +95% 이상** 올랐어요. 1x 숏이 청산되는 구간이에요. 22%는 추가로 +50% 이상 올랐어요.
- 펀딩이 플러스(롱이 지불)일 때 오히려 더 올랐어요(7일 평균 +9.5%). 펀딩 마이너스(숏 쏠림)는 특별히 더 위험하지 않았어요.
- 상장 30일 이내 코인의 펌핑은 더 이어졌어요(7일 평균 +10.8%).

### 3. 펌핑 직후 무조건 숏도 손실이에요

1x, 7일 보유 기준이에요.

- 신호 직후 숏, 손절 없음: 승률 65%, 중앙값 +9.2%인데 **평균 −2.3%**, 청산 10.6%
- +30% 손절을 걸면 평균 −1.3%
- 4시간·24시간·72시간 늦게 들어가도 평균은 플러스가 되지 않았어요.

### 4. 롱숏 계정비율로 위험한 펌핑과 좋은 펌핑이 갈렸어요

1x, +30% 손절, 7일 보유 기준이에요. 신뢰구간은 같은 달 펌핑끼리 묶어서 월 단위로 리샘플한 부트스트랩이에요.

| 신호 시점 조건 | 거래 수 | 평균 | 승률 | 평균의 90% 구간 | 2021-12..2024 | 2025..2026 |
|---|---|---|---|---|---|---|
| 조건 없음 | 3,337 | −1.0% | 55% | −1.9% ~ −0.1% | −1.2% | −1.0% |
| 롱숏 계정비율 > 1.5 | 1,072 | +1.7% | 61% | +0.1% ~ +3.3% | +1.3% | +1.8% |
| 롱숏 계정비율 > 1.5 그리고 4시간 OI +50% 이상 | 237 | **+5.6%** | 70% | +2.8% ~ +7.9% | +4.3% (n=31) | +5.8% (n=206) |
| 롱숏 계정비율 < 0.7 | 488 | **−4.6%** | 46% | −6.5% ~ −2.8% | −3.2% | −5.4% |

- **계정 대부분이 숏인 펌핑(비율 < 0.7)은 스퀴즈가 이어졌어요.** 추가 +20%가 먼저 올 확률이 52%, −20%가 먼저 올 확률은 37%였어요. 숏을 정리해야 하는 신호로 쓸 만해요.
- **계정 대부분이 롱이고 OI가 급증한 펌핑**은 숏이 플러스였어요. 레버리지 롱이 몰린 펌핑이라 털리는 쪽이에요.
  - 거래당 증거금 5%를 쓰면 누적 +92%, 최대 낙폭 −8%였어요.
  - 동시 보유는 최대 14개였어요.
  - 수익 대부분은 2025~2026년에서 나왔어요.

### 5. 양계장에 롱숏비율 필터를 붙여도 플러스가 안 됐어요

`farm_filter.py` 결과예요. 100위 밖, 1x, 30일 보유 기준이고, 시작일 운을 줄이려고 0/7/14/21일씩 엇갈린 4개 스케줄의 평균을 냈어요.

- 진입 필터: 진입 시점(전날 마지막 5분 스냅샷) 롱숏 계정비율이 낮은 코인은 제외
- 청산 규칙: 보유 중 펌핑 신호가 뜨고 그때 비율이 낮으면 청산

전체 표는 [`results/farm_filter.md`](results/farm_filter.md)에 있어요.

| 규칙 | 2025-01..2026-10 연환산 / 최대 낙폭 | 2022..2024 연환산 / 최대 낙폭 |
|---|---|---|
| 필터 없음 | −9% / −56% | −53% / −93% |
| +30% 손절만 | **−1% / −45%** | −36% / −80% |
| 진입 시 비율 < 1.0 제외 | −10% / −57% | −58% / −94% |
| 펌핑 신호 시 청산 (비율 상관없이) | −4% / −51% | −50% / −92% |
| 펌핑 신호 + 비율 < 1.0일 때만 청산 | −5% / −54% | −52% / −92% |
| 진입 < 1.0 제외 + 신호·비율 < 1.0 청산 + +30% 손절 | −2% / −46% | −40% / −81% |

- **진입 시점 롱숏비율은 청산률을 거의 못 바꿨어요(7.1% → 6.9%).** 펌핑 순간에는 의미 있던 비율이, 아무 때나 진입하는 시점에는 잡음이었어요.
- 펌핑 신호 청산은 청산률을 7.1%에서 2.3%로 줄였지만, 일찍 닫은 숏의 수익도 같이 놓쳤어요.
- 2025~2026년은 거래당 평균 +0.3%로 거의 본전이에요. 그래도 나쁜 달이 몰리면서 복리로는 마이너스가 됐고, 최대 낙폭이 −45% 이상이에요.

**진입 시점 특징으로 터질 코인을 미리 고를 수 있나?** `blowup_features.py`로 확인했어요. 결과는 `results/blowup_*.md`에 있어요.

- 2025~2026년에는 코인 나이가 가장 잘 갈랐어요.
  - 상장 7개월 미만: 청산률 12.7%, 평균 −2.6%
  - 3.5년 이상: 청산률 3.5%, 평균 +2.4%
- 하지만 2022~2024년에는 반대로 오래된 코인이 더 나빴어요. 변동성, 롱숏비율, 직전 수익률도 두 기간에 일관된 패턴이 없었어요.
- **두 기간에 공통으로 통하는 사전 필터는 찾지 못했어요.**

### 6. 크게 오른 날에만 숏 (2025-01..2026-10)

`pump_day_short.py` 결과예요. 전체 표는 [`results/pump_day_short_2025_2026.md`](results/pump_day_short_2025_2026.md)에 있어요.

- 조건: 100위 밖 코인이 UTC 일봉 종가 기준으로 전날보다 X% 이상 오른 날
- 진입: 다음 날 00시 시가에 1x 숏. 코인당 한 포지션씩만 잡아요.
- 포트폴리오:
  - 자본을 50칸으로 나눠 칸당 증거금 2%를 써요.
  - 칸이 다 차면 새 신호는 건너뛰어요.
  - 매일 종가로 평가해요.

| 조건 | 보유 | 손절 | 거래 수 | 거래당 평균 | 승률 | 포트폴리오 연환산 | 최대 낙폭 |
|---|---|---|---|---|---|---|---|
| +10% 상승일 | 7일 | 없음 | 7,079 | −0.1% | 62% | −46% | −82% |
| +10% 상승일 | 30일 | +30% | 5,477 | −0.8% | 50% | +1% | −56% |
| +20% 상승일 | 7일 | +30% | 2,196 | −1.2% | 54% | −28% | −52% |
| +30% 상승일 | 7일 | +30% | 1,048 | −0.0% | 53% | −2% | −21% |
| +10% 상승일 + 롱숏비율 > 1.5 | 7일 | 없음 | 4,063 | +0.8% | 64% | −6% | −49% |
| **+30% 상승일 + 롱숏비율 > 1.5** | 7일 | 없음 | 230 | **+2.1%** | 73% | **+5%** | **−8%** |
| **+30% 상승일 + 롱숏비율 > 1.5** | 30일 | 없음 | 218 | **+3.3%** | 71% | **+7%** | −13% |
| +10% 상승일 + 롱숏비율 < 0.7 | 7일 | 없음 | 546 | −3.2% | 58% | −18% | −35% |

- **+10% 상승일 진입은 아무 때나 진입하는 것과 거의 같았어요.** 거래당 평균이 0 근처예요.
- **포트폴리오가 거래당 평균보다 훨씬 나빴어요.** 신호가 22개월에 7천 건이라 칸이 자주 꽉 찼고, 3천 건을 건너뛰었어요.
  - 건너뛴 거래는 평균 +1.1%였고, 실제로 잡은 거래는 −0.9%였어요.
  - 소형코인 20% 이상이 같이 오른 날의 펌핑은 오히려 잘 되돌렸어요(평균 +2.8%).
  - 혼자 오른 코인(같은 날 오른 코인이 2% 미만)은 더 위험했어요(평균 −2.6%, 청산 8%).
  - 칸이 혼자 오른 코인으로 먼저 차버려서, 정작 좋은 날에는 자리가 없었던 셈이에요.
- 상승폭 기준만 +20%, +30%로 올려도 나아지지 않았어요.
- **롱숏비율 > 1.5(계정 대부분이 롱) + +30% 상승일 조합만 플러스**였어요.
  - 다만 22개월에 230건뿐이라 대부분의 자본이 놀아서 연환산은 +5~7%예요.
  - 롱숏비율 < 0.7(숏 쏠림)은 어떤 조합에서도 마이너스였어요.
- 롱숏비율 효과는 2025~2026년 데이터에서 찾은 거라, 같은 기간 검증은 표본 내 결과예요.

### 7. 손절·청산 난 코인은 다시 숏하지 않기

`pump_day_short.py --ban` 결과예요. 한 번이라도 손절이나 청산이 난 코인은 그 뒤로 숏하지 않아요.

| 조건 (7일 보유, +30% 손절) | 2025-01..2026-10 거래당 / 연환산 / 최대 낙폭 | 2022..2024 거래당 / 연환산 / 최대 낙폭 |
|---|---|---|
| +10% 상승일, 제외 규칙 없음 | +0.1% / −35% / −73% | — |
| **+10% 상승일, 손절 코인 제외** | **+1.2% / +14% / −40%** | −1.5% / −13% / −57% |
| +10% 상승일 + 롱숏비율 > 1.5, 손절 코인 제외 | +1.5% / +25% / −31% | (롱숏비율 데이터 부족) |
| +30% 상승일, 손절 코인 제외 | +0.2% / +1% / −15% | +3.0% / +4% / −6% (183건) |

- 2025~2026년에는 제외 규칙이 크게 도움이 됐어요. 반복해서 펌핑하는 코인을 걸러준 셈이에요.
- 그런데 **2025년 +14%는 1~3월에 다 벌었어요.**
  - 자본이 1에서 1.78까지 올라갔어요.
  - 그 뒤 2026-10까지 1.28로 내려왔어요(고점 대비 −28%).
  - 제외된 코인이 쌓이면서 월 거래 수도 100~300건에서 50건 안팎으로 줄었어요.
- **2022~2024년에는 같은 규칙이 연 −13%, 최대 낙폭 −57%**였어요. 다른 기간에서는 재현되지 않았어요.

### 8. 고정 익절을 넣고 조합 찾기

`tp_grid.py`(실행)와 `tp_grid_report.py`(정리) 결과예요. 전체 표는 [`results/tp_grid.md`](results/tp_grid.md)에 있어요.

탐색한 조합(기간마다 1,152개, 두 기간을 따로 돌렸어요):

| 설정 | 후보 |
|---|---|
| 상승폭 | +10 / +20 / +30% |
| 익절 | −10 / −15 / −20 / −30 / −40 / −50% |
| 손절 | +15 / +20 / +30 / +50% |
| 최대 보유 | 3 / 7 / 14 / 30일 |
| 손절한 코인 버리기 | 적용 / 미적용 |
| 롱숏비율 필터 | 없음 / > 1.5 |

같은 1시간봉 안에서 손절과 익절이 둘 다 닿으면 손절이 먼저 된 걸로 쳤어요(보수적). 익절은 지정가라 메이커 수수료 0.02%를 적용했어요.

- **2025~26년 최고 조합은 2022~24년에 무너졌어요.**
  - 조합: +10% 상승일, 익절 −40~50%, 손절 +15%, 7일, 손절한 코인 버리기
  - 2025~26년: 연 +20%, 최대 낙폭 −26%
  - 2022~24년: 연 −7~−8%

- 시간봉 +30%에 필터를 넣으면 수익은 가장 작지만($26,200), 낙폭이 −18%로 가장 작아요.

### 16. 2025년과 2026년은 왜 이렇게 다른가

최종 규칙(STRATEGY.md) 기준이고, 금액은 거래당 15%예요. 2025년은 +106%, 2026년은 10월까지 +8%였어요.

- **손절 코인 제외 목록 때문은 아니에요.** 2026-01-01부터 목록을 비우고 새로 시작해도 2026년은 +4%였어요. 2025년은 새로 시작하면 +100%였어요.
- **메이저 방향 때문도 아니에요.** 두 해 모두 BTC가 하락했어요(2025년 −7%, 2026년 10월까지 −12%).
- **2026년 2~4월에 크게 빠졌어요(−27%).**
  - 이 기간 손절 비율이 50~57%, 승률이 29~48%였어요.
  - 5~10월만 보면 다시 +47%였어요.
- **신호 하나당 수익이 해마다 줄고 있어요.** 필터를 통과한 모든 신호 기준이에요.

  | 연도 | 거래당 | 손절 비율 |
  |---|---|---|
  | 2024 | +3.0% | 25% |
  | 2025 | +1.9% | 35% |
  | 2026 | +0.5% | 43% |

  - 중앙값은 +7% 안팎으로 그대로예요. 대부분은 여전히 되돌렸다는 뜻이에요.
  - 다만 손절에 걸린 뒤 3일 안에 진입가 아래로 돌아온 비율이 35%(2025)에서 50%(2026)로 늘었어요. 펌핑 직후 한 번 더 튀는 경우가 많아졌다는 뜻이에요.
  - +20% 펌핑 신호 자체도 분기당 40~150건(2024)에서 300~480건(2025~26)으로 늘었어요.

### 17. 변동성 기반 손절, 그리고 3일 컷이 놓치는 이익

- **변동성 기반 손절**
  - 계산법: 손절폭 = k × ATR%. ATR%는 일봉 기준 최근 14일 평균 변동폭을 종가로 나눈 값이에요. 손절폭은 8~50% 사이로 제한했어요.

    - 고정 +15%: $20,800 (낙폭 −12%)
    - 고정 +20%: $23,700 (낙폭 −16%)
    - ATR 기반은 전부 이보다 못했어요.
  - 2025-07~2026-10(검증 구간)에서는 넓은 ATR 손절이 가장 좋았어요.
    - 3 × ATR(손절폭 중앙값 +39%): $38,400
    - 고정 +15%: $19,200
  - 구간에 따라 승자가 바뀌어서 일관된 개선은 아니에요. 넓은 손절은 낙폭도 −35~−38%로 커졌어요.

  - 계속 들고 있었을 때 평균은 +3.8%로, 3일에 끊는 것(+4.5%)보다 약간 낮아요.

- **보유 기간 제한을 2~10일로 바꿔보기** ([`results/hold_days.md`](results/hold_days.md), 1만 달러, 거래당 15%)
