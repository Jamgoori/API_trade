# pumpfade — 잡코인 펌핑 되돌림 숏 + 상장빔 숏

`research/STRATEGY.md`의 두 규칙(메인: 일봉 +20% 펌핑 되돌림, 상장빔: 기존 코인의 신규 상장)을 돌리는 봇이에요. 모드가 두 개 있어요.

- **페이퍼 모드** (`paper`): 실시간 데이터로 가상 체결만 기록해요. 공개 데이터만 써서 API 키가 필요 없어요.
- **실거래 모드** (`live`): 바이낸스 선물 계정에 진짜 주문을 넣어요. 아래 [실거래](#실거래-live) 부분을 끝까지 읽고 쓰세요.

## 하는 일

| 한국 시간 | 하는 일 |
|---|---|
| 매일 09:01 | 전날 일봉이 마감되면 신호를 확인해요(거래대금 100위 밖, +20%, 롱숏비율, 메이저, 윗꼬리, 펀딩비). 신호와 탈락 이유를 모두 기록해요 |
| 09:01 | 가상 진입을 기록해요. 09:00 가격 +0.5%에 숏 지정가를 걸어둔 걸로 쳐요. 비교용 장부의 시장가 물량은 **실제 호가창**에 내 주문 크기만큼 팔았다고 계산해서 슬리피지를 재요 |
| 09:00~10:00 | 1분봉이 지정가를 **뚫고 올라가면** 체결로 봐요. 살짝 닿기만 한 건 체결로 치지 않아요 |
| 10:00 | 안 잡힌 지정가는 취소하고 시장가로 진입해요(호가창 기준, 최대 −0.3%까지만 체결) |
| 30초마다 | 1분봉으로 익절(−15%)과 손절(+15%)을 확인해요. 한 봉에서 둘 다 닿으면 손절로 쳐요. 손절은 그 순간의 호가창 슬리피지까지 반영해요 |
| 매시간 | 바이낸스 실제 펀딩비 기록으로 펀딩을 정산해요 |
| 진입 48시간 후 | 남은 포지션을 시장가로 정리해요(호가창 기준) |
| 1분마다 | **상장빔 감시**: 업비트·빗썸 원화마켓과 바이낸스 현물(USDT)에 새 마켓이 생겼는지 봐요. 바이낸스 선물에 30일 이상 있던 코인이면, 거래가 시작된 시간대 +1시간에 선물 숏을 시장가(최대 −0.3%)로 잡아요. 가격이 전혀 다른 같은 이름 코인은 걸러요 |
| 매일 09:35 | 장부별 성과 요약을 남겨요. 텔레그램을 설정했으면 텔레그램으로도 보내요 |

같은 신호를 장부 네 개로 따로 기록해요.

| 장부 | 진입 방식 | 보유 |
|---|---|---|
| `limit` (전략 그대로) | 09:00 가격 +0.5% 지정가 → 10시까지 안 잡히면 시장가 | 48시간 |
| `market` | 전부 09:00 시장가 (비교용) | 48시간 |
| `half` | 절반 시장가 + 절반 지정가 (비교용) | 48시간 |
| `limit_3d` | limit과 같음 (비교용) | 72시간 |

장부마다 1만 달러로 시작하고, 신호 하나에 그 장부 자본의 12%를 써요(동시에 최대 7개). 메인 규칙에서 손절한 코인은 장부마다 따로 제외 목록에 넣어요. 상장빔은 모든 장부에 똑같이 기록되고(진입은 항상 시장가), 같은 코인을 이미 들고 있으면 건너뛰어요. 리포트에서 장부 아래 `└ main`, `└ listing` 줄로 규칙별 성적을 따로 보여줘요.

## 실행 방법

### 내 PC에서 (Windows / Mac)
Python 3.11 이상이 필요해요. 저장소 폴더에서 아래 순서로 실행하세요.

```bash
pip install requests python-dotenv
```

```bash
python -m pumpfade scan
```

```bash
python -m pumpfade paper
```

- `scan`: 어제 신호를 확인만 해요. 포지션은 안 열어요.
- `paper`: 봇이 계속 돌아가요. 창을 닫거나 PC가 꺼지면 멈춰요.
- 09:30이 지나서 켜면 그날 신호는 건너뛰어요. 늦은 가격으로 들어가는 걸 막기 위해서예요. 그래서 **매일 09:00 전에는 켜져 있어야 해요.**

### VPS에서 (24시간)

```bash
bash deploy/install_pumpfade.sh
```

```bash
sudo systemctl start pumpfade
```

```bash
journalctl -u pumpfade -f
```

### 결과 보기

```bash
python -m pumpfade report
```

```bash
python -m pumpfade status
```

- `report`: 장부별 성과를 보여줘요.
- `status`: 지금 열린 포지션과 대기 중인 지정가를 보여줘요.

기록은 `data/pumpfade.sqlite`에 쌓여요. 봇을 껐다 켜도 이어서 기록해요.

### 텔레그램 알림 (선택)
`.env`에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 넣으면 진입·청산·매일 요약을 보내줘요.

1. 텔레그램에서 **@BotFather**(파란 체크)를 찾아 `/newbot` → 봇 이름 → `bot`으로 끝나는 아이디를 정하면 **토큰**을 줘요.
2. BotFather가 준 링크로 내 봇에 들어가 **시작(Start)** 을 눌러요.
3. `.env`에 `TELEGRAM_BOT_TOKEN=토큰`을 넣고 `python -m pumpfade telegram`을 실행하면 `TELEGRAM_CHAT_ID=...` 줄을 알려줘요. 그 줄을 `.env`에 넣어요.
4. `python -m pumpfade telegram`을 한 번 더 실행하면 테스트 메시지가 와요. 그다음 봇을 재시작해요.

봇이 돌고 있을 때 내 봇 채팅방에 이렇게 보내면 30초 안에 답해요(조회만 돼요).

| 보내는 말 | 답 |
|---|---|
| `/status` 또는 `상태` | 자산, 고점 대비, 신호당 비율, 지금 포지션(진입가·손절·익절·남은 시간), 마지막 09:00 확인 날짜 |
| `/report` 또는 `성과` | 규칙별 성적 요약 |

### 봇이 죽으면 알림 받기 (healthchecks.io, 무료)

노트북이 꺼지거나 인터넷이 끊기면 봇은 스스로 알릴 수 없어요. 그래서 바깥 감시 서비스를 써요. 봇이 5분마다 "살아 있음" 신호를 보내고, 신호가 끊기면 감시 서비스가 텔레그램(또는 메일)으로 알려줘요.

1. healthchecks.io 에 가입해요(무료).
2. **Add Check**를 누르고 **Period 5 minutes**, **Grace 15 minutes**로 맞춰요.
3. **Integrations → Telegram**에서 안내대로 연결해요. 안 해도 가입한 메일로는 알림이 와요.
4. 체크의 **Ping URL**(`https://hc-ping.com/...`)을 복사해서 `.env`에 `PUMPFADE_HEARTBEAT_URL=...`로 넣고 봇을 재시작해요.

노트북 꺼짐, 인터넷 끊김, 봇 멈춤, API 키 오류(IP 변경 등)가 20분 넘게 이어지면 알림이 와요. 다시 살아나면 "up" 알림도 와요.

## 리포트 읽는 법

| 항목 | 뜻 | 백테스트 기준 |
|---|---|---|
| per signal | 신호 하나의 증거금 대비 평균 수익 | 메인 +2.0%, 상장빔 +2.8% |
| win | 플러스로 끝난 신호 비율 | 메인 63%, 상장빔 67% |
| TP/stop/time | 끝난 방식 (익절 / 손절 / 시간 정리) | 34% / 31% / 35% |
| market slip | 시장가 진입(10시 대비책, 비교 장부) 때 호가 중간값 대비 실제 슬리피지 | 0.1~0.3% 가정 |
| stop slip | 손절 때 호가 기준 슬리피지 | 0.5~1.0% 가정 |
| limit fill | +0.5% 지정가가 1시간 안에 잡힌 비율 | 86% (닿기만 해도 체결로 친 값이라 실제는 더 낮을 수 있어요) |

## 페이퍼 통과 기준 (1~2개월)

- 신호가 백테스트 코드와 같게 나와야 해요. 2026-10-17~10-30의 14일로 비교했을 때 20건이 모두 일치했어요.
- 10시 시장가 진입과 비교 장부의 시장가 슬리피지가 평균 **0.3% 이하**여야 해요.
- 지정가 체결률이 **75~80% 이상**이어야 해요.
- 빠진 날이나 오류가 없어야 해요.

통과하면 테스트넷을 거쳐 실거래 5%로 시작하고, 조건을 채우면 12%로 올려요. 자세한 단계는 `research/STRATEGY.md`의 크기 표를 따라요.
기본은 `limit` 장부예요. `market`, `half` 장부는 실제 슬리피지가 아주 작게 나올 때 다시 비교해보려고 남겨둔 거예요.

## 설정

환경변수로 바꿀 수 있어요(`.env`에 넣어도 돼요).

| 변수 | 기본값 | 내용 |
|---|---|---|
| `PUMPFADE_START_EQUITY` | 10000 | 장부별 시작 자본 |
| `PUMPFADE_MARGIN_FRACTION` | 0.12 | 신호당 증거금 비율 |
| `PUMPFADE_DB` | data/pumpfade.sqlite | 기록 파일 |
| `PUMPFADE_BASE_URL` | https://fapi.binance.com | 바이낸스 선물 API 주소 |
| `PUMPFADE_SPOT_URL` | https://data-api.binance.vision | 바이낸스 현물 시세 주소 (현물 신규 상장 감시용) |
| `PUMPFADE_WATCH_LISTINGS` | 1 | 0으로 두면 상장빔 감시를 끄고 메인 규칙만 기록 |

전략 수치(익절·손절, 필터 기준 등)는 `pumpfade/config.py`의 `Strategy`에 있어요.

## 실거래 (live)

### 주문이 나가는 방식

| 한국 시간 | 메인 규칙 |
|---|---|
| 09:01 | 신호 코인마다 격리(isolated) 1배로 맞추고, 09:00 시가 +0.5%에 **숏 지정가(GTC)** 를 걸어요. 수량은 계정 자산 × 신호당 비율 |
| 09:01~10:00 | 일부라도 체결되면 바로 **손절 +15%(STOP_MARKET)** 와 **익절 −15%(TAKE_PROFIT_MARKET)** 를 거래소에 걸어요. 둘 다 `closePosition`이라 포지션 전체를 닫아요 |
| 10:00 | 남은 지정가를 취소하고 나머지를 IOC로 팔아요. 최우선 매수호가에서 −0.3%보다 싼 가격엔 안 팔아요 |
| 진입 48시간 후 | 남아 있으면 시장가(reduceOnly)로 사서 정리해요 |

상장빔은 예정 시각에 IOC(최대 −0.3%)로 바로 숏을 잡고, 손절·익절·48시간은 똑같아요.

손절·익절 주문은 **거래소에 걸려 있어서 봇이 꺼져도 작동해요.** 봇은 30초마다 거래소에 실제 포지션·주문·체결을 물어보고 장부를 맞춰요. 껐다 켜도 이어서 관리해요.

안전장치:
- 손절 주문이 거부되면 그 포지션을 **바로 시장가로 정리**하고 텔레그램으로 알려요.
- 거래소 응답이 잠깐 늦어도 청산으로 착각하지 않게, 포지션이 0으로 **두 번(25초 이상 간격)** 보여야 끝난 걸로 쳐요.
- 봇이 10시에 꺼져 있었으면 10:30이 지난 뒤엔 IOC 진입을 하지 않아요(늦은 가격으로 들어가지 않기).
- 봇이 안 연 포지션(직접 잡은 포지션)은 건드리지 않고 알림만 보내요.
- 자산 고점 대비 **−25%** 면 신호당 비율을 2/3로 줄이고 새 고점에서 되돌려요. **−35%** 이거나 최근 100건 평균이 **−1.5% 미만**이면 새 진입을 멈춰요.
- 메인 규칙에서 손절한 코인은 다시 진입하지 않아요.

### 계정 준비

1. 봇 전용 **서브계정**을 쓰는 걸 추천해요. 봇은 포지션을 정리할 때 그 코인의 미체결 주문을 전부 취소해요.
2. 선물 설정: **단방향(One-way) 포지션 모드**, **단일 자산(Single-Asset) 모드**여야 해요. 격리 마진은 멀티에셋 모드에서 안 돼요.
3. API 키: **선물 거래 권한만** 켜고, **출금은 끄고**, **IP 제한**(VPS 고정 IP)을 거세요.
4. 키는 **VPS의 `.env` 파일에만** 넣으세요. 채팅이나 깃허브에 붙여넣지 마세요. `.env`는 git에 안 올라가요.
5. VPS는 미국 서버를 피하세요. 바이낸스가 미국 IP를 막아요. 도쿄·싱가포르·서울 리전이 무난해요.

### 순서

**1단계 — 테스트넷 점검 (진짜 돈 아님)**

testnet.binancefuture.com 에서 테스트넷 키를 만들어 `.env`의 `BINANCE_TESTNET_API_KEY`, `BINANCE_TESTNET_API_SECRET`에 넣고:

```bash
python -m pumpfade selftest
```

시간 동기화 → 단방향 모드 확인 → 격리 1배 설정 → 지정가 주문·조회·취소 → 손절(algo) 주문·조회·취소 → 최소 수량 숏 진입 → 손절·익절 걸기 → 시장가 청산 → 체결 내역 조회까지 해보고 `ALL OK`가 나와야 해요.

**2단계 — 실계정 점검 (주문은 바로 취소)**

`.env`에 `BINANCE_API_KEY`, `BINANCE_API_SECRET`을 넣고:

```bash
python -m pumpfade selftest --mainnet
```

체결되지 않을 먼 가격에 주문을 넣었다 바로 취소해요. 돈은 안 움직여요.

실제 체결까지 해보려면 최소 주문이 5달러인 코인으로 해요. 약 6달러어치 숏을 잡고, 손절·익절을 걸었다가, 바로 닫아봐요(수수료 1센트 미만). 테스트넷 키를 못 만들었으면 이걸로 1단계를 대신해도 돼요.

```bash
python -m pumpfade selftest --mainnet --fill --symbol DOGEUSDT
```

**3단계 — 실거래 5%로 시작**

`.env`의 `PUMPFADE_LIVE_MARGIN_FRACTION`은 처음 `0.05`예요.

```bash
bash deploy/install_pumpfade.sh live
```

```bash
sudo systemctl start pumpfade-live
```

```bash
journalctl -u pumpfade-live -f
```

PC에서 직접 돌릴 땐 `python -m pumpfade live --i-understand-live` 예요. 매일 09:00 전에 켜져 있어야 해요.

**4단계 — 12%로 올리기**

2~4주 동안 주문·체결·손절·익절·48시간 정리가 기대대로 됐고, 10시 IOC 슬리피지가 0.3% 이하였으면 `.env`에서 `PUMPFADE_LIVE_MARGIN_FRACTION=0.12`로 바꾸고 재시작해요.

```bash
sudo systemctl restart pumpfade-live
```

### 윈도우에서 자동 시작

윈도우는 업데이트로 재부팅되면 봇이 꺼져요. 작업 스케줄러에 등록해두면 컴퓨터가 켜질 때 **로그인하지 않아도** 봇이 켜지고, 봇이 꺼지면 30초 뒤 다시 켜요.

1. 직접 켜둔 봇 창이 있으면 Ctrl+C로 먼저 끄세요(봇은 두 개가 동시에 못 돌게 막혀 있어요).
2. 시작 버튼에서 PowerShell을 **마우스 오른쪽 → 관리자 권한으로 실행**해요.

```bash
cd $HOME\API_trade
```

```bash
powershell -ExecutionPolicy Bypass -File deploy\windows\install_autostart.ps1
```

로그 보기:

```bash
Get-Content data\pumpfade-live.log -Tail 30 -Wait
```

멈추기 (`-Remove`를 쓰면 자동 시작까지 지워요):

```bash
powershell -ExecutionPolicy Bypass -File deploy\windows\install_autostart.ps1 -Stop
```

코드를 업데이트(`git pull`)한 뒤에는 `-Stop`으로 멈추고 `Start-ScheduledTask pumpfade-live`로 다시 켜요.


- `status --live`: 지금 들고 있는 포지션, 진입가, 손절·익절 가격
- `report --live`: 계좌 자산, 고점 대비 낙폭, 지금 신호당 비율, 규칙별 성적, 지정가 체결 비율

비상시엔 봇을 멈추고 전부 정리해요.

```bash
sudo systemctl stop pumpfade-live
```

```bash
python -m pumpfade flatten --i-understand-live
```

`flatten`은 봇이 연 포지션만 주문 취소 후 시장가로 정리하고, **새 진입을 멈춘 상태로** 둬요. 진입이 멈춘 상태(낙폭 −35%나 `flatten` 뒤)에서 다시 시작하려면 멈춤을 풀고 봇을 켜요.

```bash
python -m pumpfade live --i-understand-live --resume
```

```bash
sudo systemctl start pumpfade-live
```

`--resume`은 멈춤만 풀고 끝나요. 자산 고점도 지금 자산으로 다시 잡아요.

### 백테스트와 다른 점

- 익절을 백테스트는 지정가(메이커 0.02%)로 쳤는데, 실거래는 TAKE_PROFIT_MARKET이라 테이커(0.05%)예요. 건당 약 0.03%p 차이라 결과에 거의 영향 없어요.
- 손절은 +15%에 닿는 순간 시장가로 나가서, 급등 중엔 +15%보다 더 비싸게 사질 수 있어요(백테스트는 0.3~0.5% 슬리피지 가정).
- 실거래 기록은 `data/pumpfade-live.sqlite`에 따로 쌓여요. 페이퍼 봇과 동시에 돌려도 서로 안 섞여요.

### 실거래 설정

| 변수 | 기본값 | 내용 |
|---|---|---|
| `BINANCE_API_KEY` / `BINANCE_API_SECRET` | 없음 | 실계정 API 키 (`.env`에만) |
| `BINANCE_TESTNET_API_KEY` / `BINANCE_TESTNET_API_SECRET` | 없음 | 테스트넷 키 (`selftest`용) |
| `PUMPFADE_LIVE_MARGIN_FRACTION` | 0.05 | 신호당 증거금 비율. 점검 후 0.12 |

낙폭 기준(−25% / −35%)과 최대 증거금 사용(90%)은 `pumpfade/config.py`의 `Settings`에 있어요.

## 보안 체크리스트

봇은 **외부에서 들어오는 연결을 받지 않아요**(포트를 열지 않음). 텔레그램으로는 조회 명령(`/status`, `/report`)만 받고, `.env`의 `TELEGRAM_CHAT_ID` 채팅에서 온 것에만 답해요. 주문을 넣거나 바꾸는 명령은 없어요. 그래서 공격면은 사실상 **API 키가 든 `.env`와 그 컴퓨터** 두 가지예요.

**바이낸스 키**
- 봇 전용 **서브계정**에 봇이 쓸 돈만 넣으세요. 최악의 경우 피해가 그 계정 안으로 한정돼요.
- 권한은 **읽기 + 선물 거래**만 켜요. 현물·마진 거래, **출금**, **유니버설 전송**은 끄세요.
- **IP 제한**을 거세요. 키가 새도 다른 곳에선 못 써요. 집 IP가 바뀌면 바이낸스에서 새 IP로 고쳐주면 돼요.
- 키는 `.env`에만 넣으세요. 채팅·메신저·깃허브·클라우드 메모에 붙여넣지 마세요. 새어 나간 것 같으면 바로 바이낸스에서 키를 지우고 새로 만드세요.
- `.env`에 있는 다른 봇(hedgebot) 키 칸은 비워두세요.

**봇 컴퓨터 (노트북/VPS)**
- 설치 스크립트는 봇을 **일반 사용자 권한**으로 돌리고, `.env`는 본인만 읽을 수 있게(600), 기록 폴더 `data/`는 본인만 열 수 있게(700) 맞춰요. 서비스에는 권한 상승 금지 같은 systemd 보호 설정이 들어 있어요.
- 방화벽은 들어오는 연결을 전부 막아요(SSH를 쓰면 `sudo ufw allow OpenSSH`를 먼저 하세요).

```bash
sudo ufw default deny incoming
```

```bash
sudo ufw enable
```

- SSH를 켤 거면 비밀번호 로그인은 끄고 키 로그인만 쓰세요.
- 우분투 자동 보안 업데이트(unattended-upgrades)를 켜두세요. 기본으로 켜져 있고 자동 재부팅은 하지 않아요.
- 그 컴퓨터로 웹서핑이나 다른 프로그램 설치는 하지 마세요.
- 디스크 암호화는 도난에 강하지만, 정전 뒤 켜질 때 암호를 입력해야 해서 봇이 자동으로 다시 안 켜져요. IP 제한을 걸어두면 노트북을 훔쳐가도 키를 다른 곳에서 못 쓰니 암호화는 선택이에요.

**텔레그램**
- 봇 토큰도 비밀이에요. 새면 누가 내 봇 이름으로 메시지를 보낼 수 있어요(거래는 못 해요). @BotFather에서 토큰을 바꾸면 돼요.
- 오류 기록과 로그에는 텔레그램 토큰, 요청 서명, API 키가 남지 않게 처리돼 있어요.
